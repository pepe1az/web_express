## Границы проверки

Для основного способа подключения теперь не нужен SSH-туннель: преподавателю подготовлены отдельные параметры прямого TLS-доступа. Личные сообщения и публикация в форуме автоматически не выполнялись.

Условия Timeweb Cloud и Supabase проверены по официальным источникам, их публичные страницы доступны с рабочей станции. Платные кластеры не создавались. Для Helios подтверждён только сетевой ответ SSH и доступность страницы входа: личная учётная запись не подтверждена, авторизованное подключение к PostgreSQL Helios не проверялось.
